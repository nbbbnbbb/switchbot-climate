センサーを配置すると、室内の分布を推定できます。

ヒートマップの読み方

丸印は配置したセンサー、その横にセンサー名と実測値を表示します。面の色は室内の有効な測定点から距離による重み付けで推定した値です。測定点が少ない場所や測定点に囲まれていない場所ほど不確かです。空気の流れや壁の断熱は計算していません。

室外センサーは点と実測値だけを表示し、室内の補間には使いません。選択時刻より未来の値や有効時間を超えた古い値は使いません。配置設定は現在の配置を過去の記録にも適用します。再生は選択期間内の実際の取得時刻に沿って進みます。
