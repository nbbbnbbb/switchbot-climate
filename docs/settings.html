04 / ROOM & SENSORS

恒温室とセンサーの配置

底面が三角形の垂直な三角柱です。単位はm。A=(0,0)、B=(幅,0)、C=(頂点X,奥行)。Zは床からの高さです。

初期寸法は仮の値です。写真からの実測ではありません。寸法を変更してもセンサーの座標はm単位の値を保ちます。

平面図 X・Y

正面図 X・Z

選んだセンサーを図上でクリック・ドラッグして配置します。平面図でX・Y、正面図でX・Zを編集します。矢印キーで0.01 m、Shift併用で0.1 m移動。外側にも配置できます。

現在の配置を過去の全記録にも適用します。センサーを移動した場合、移動前の空間分布を正確に再現するには元の配置に戻してプレビューしてください。

共有設定の保存と管理者認証について

設定の閲覧とプレビューは誰でも利用できます。保存には、このリポジトリへ書き込みできるGitHubアカウントの認証が必要です。認証情報は保存する際にGitHubへ直接送信し、このサイトの保存データには含めません。

設定を直接編集する場合は、GitHubの設定ファイルからも変更できます。

ADMIN ACCESS

共有設定を保存

GitHubの書き込み権限で認証します。この設定は、すべての閲覧者の表示に適用されます。

トークンはこの保存処理にだけ使い、ブラウザーや公開ファイルには保存しません。SwitchBotのToken・Secretとは別です。

GitHubトークンの準備方法
  1. GitHubでFine-grained tokenを作成
  2. Repository accessで「Only select repositories」を選び、switchbot-climateだけを指定
  3. Repository permissionsのContents → Read and writeを指定
  4. 作成したトークンをこの入力欄へ貼り付け

必要な権限はこのリポジトリのContentsだけです。
